# Archived Planline sample-workflow prototype

This directory preserves the earlier three-step sample UI and source-preflight API that were previously uploaded under docs/planline-webui/.

It is **not the active application**. The current app is in the repository-root web/ directory and is served by planline/api.py; it includes the YOLO detection/review workflow and its associated tests.

The archived prototype is kept as a design reference only. Its sample measurements and sample DXF are illustrative and must not be confused with detections or geometry produced by the active application.
